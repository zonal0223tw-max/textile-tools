# 裁片量測台 · Card-Scale Measure

平鋪一件衣服、旁邊放一張**信用卡**，從正上方拍張照 →
點信用卡四角定標 → 描裁片輪廓 → **真實尺寸（邊長／周長／面積／外框）即時算出**。

> Live：https://zonal0223tw-max.github.io/card-measure/

## 靈魂
iPhone 的「測距」用 ARKit/LiDAR，網頁拿不到。但平鋪的衣服是個**平面** —
放一張已知尺寸的信用卡（ISO ID-1 = 85.6×54mm），點它四個角，就能解出一個
**homography（單應性矩陣）**，一魚兩吃：

1. **像素 → mm 比例尺**
2. **透視校正** —— 連斜拍都能量準（梯形變形會被拉回正視圖）

所有 mm 尺寸由「點座標 × H」**湧現**，零 hardcode；拖任一個點 → 全部即時重算。

## 用法
1. **載入**：衣服平鋪、旁邊放信用卡，盡量正上方拍。
2. **信用卡定標**：沿卡邊順時針點四個角。
3. **描裁片**：沿輪廓點頂點，回起點封閉。周長／面積／各邊長即時顯示。
4. **核對／匯出**：可點兩個已知距離核對精度；匯出 SVG（1:1 原寸可印拼版）或量測 JSON。

## 誠實邊界
這是**推估模擬**工具：手機鏡頭畸變、衣服厚度皺褶、布料延展都會帶進誤差，
信用卡離裁片越遠誤差越大。適合 QC 平量、打版參考、估尺寸；正式工業版仍需人工校版。
右上角「信心」晶片會把比例一致性攤給你看。

## 技術
零相依、單檔 HTML + Canvas 2D。Homography 為純 JS 4 點 DLT 解算（無 OpenCV）。
`window.__app.test()` 內建合成案例自驗（卡 85.6×54mm、200px 方塊 → 100mm 方）。
