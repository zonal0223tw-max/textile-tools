裁片量測台 · 怎麼用

平面 + 一張信用卡 = 不用 LiDAR 也能量真實尺寸

  1. 載入：衣服平鋪，旁邊放一張信用卡，盡量從正上方拍。
  2. 信用卡定標：沿卡邊順時針點四個角。系統用 85.6×54mm 解出比例尺＋透視校正。
  3. 描裁片：沿裁片輪廓點頂點，回到起點封閉。周長／面積／各邊長即時算出。
  4. 核對／匯出：可點兩個已知距離核對精度；匯出 SVG(原寸可印)或量測 JSON。

手勢

  1. 單指點 = 加一個點；拖既有點 = 微調。
  2. 單指拖空白 = 平移；雙指 = 縮放看細節。
這是推估模擬工具：手機鏡頭畸變、衣服厚度皺褶、布料延展都會帶進誤差，信用卡離裁片越遠誤差越大。適合 QC 平量、打版參考、估尺寸；要做正式工業版仍需人工校版。右上角「信心」晶片會把比例一致性攤給你看。
